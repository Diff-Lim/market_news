# 뉴스레터 요청함

다음 호에 추가로 다뤘으면 하는 내용을 적는 곳이에요. GitHub 웹이나 모바일 앱에서 이 파일을 열어 연필(✏️) 버튼으로 고치고 커밋하면 돼요.

## 쓰는 법
- 해당 산업 제목 아래에 `- [ ] 요청 내용` 한 줄을 추가해요.
- 다음 정기 발행 때 반영되고, 반영되면 `- [x] 요청 내용 → 반영: YYYY-MM-DD` 로 바뀌어요.
- `## 공통` 에 적은 요청은 관련 있는 모든 산업 뉴스레터에서 반영해요. 마지막으로 반영한 산업이 체크해요.
- 계속 지켜볼 종목·키워드는 여기 말고 `config/watchlist.json` 에 넣어요.

예)
- [ ] 알테오젠 키트루다 SC 관련 최근 소송·로열티 이슈 정리해줘
- [ ] 이번 주 미국 전력기기 업체 실적 발표 일정 알려줘
- [ ] HBM4 납품 관련 삼성전자·SK하이닉스 비교 관점 넣어줘
